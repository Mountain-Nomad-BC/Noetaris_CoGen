# ADR-002: Separate authority planes for evidence, indexes and executable skills

Status: Accepted, October 12 2026.

Decision: Claim promotion, retrieval index activation and executable skill release are independently authorized state transitions. None is permitted from model output alone. Skill execution stays disabled until an independently enforced Linux sandbox and real work admission mechanism exist.

Rationale: Good retrieval does not imply true data, successful tests do not imply authorized execution and a documented policy is not an OS enforcement mechanism.
