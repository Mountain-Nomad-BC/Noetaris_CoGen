# Remaining blockers and scope exclusions

AMD GPU execution and performance remain pending until an approved Linux ROCm host is supplied.
The hackathon submission's actual event eligibility, deadline, partner requirements and publication
requirements must be verified against the organizer's current materials before submission.
This build does not submit anything or claim partner qualification.

Central identity/security integration is staged and disabled. Production activation requires separate
authorization and a validated adapter. Production OIDC/TLS, per-user/tenant identity, backups on remote
storage, egress policies and external audit anchoring remain outside this local demonstration.

Bounded learning means deterministic conflict reflections and source-backed human-reviewed proposals,
not self-training or model weight updates. PX's full memory fabric/Gremlin/control plane is not imported
or certified. PX Doctor's observed blockers are retained, not repaired in the upstream project.

Retrieval is PostgreSQL lexical indexing, not semantic/vector retrieval. PDF text extraction does not provide
OCR, reliable visual/table semantics or a full PDF viewer. Canonical source hashes and page/line excerpts
remain inspectable. Full TurnBurn generations, independent index activation/rollback, streaming,
voice, generic executable skills, cloud partner workflows and advanced autonomous orchestration are deferred.

Publication is blocked by default. The generated public-safe preview contains selected documentation
and test summaries only, not the restricted application source. Neither corporate datasets nor credentials
are included. Review current test evidence and security scan limitations before extending deployment scope.
